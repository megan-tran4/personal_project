Context

Ventra is the official app for the Chicago public transportation system. Although it is the official app, both residents and non-resident users struggle to navigate through the app. Many residents stated that they only use the app to add money to their card, ignoring all the navigation features on the app. The crowding dashboard is also very hidden and requires navigating to a browser, making it a highly unused feature.

1. Research

We completed 12 interviews from people who have used Ventra to assist with their trips around Chicago. We found the following trends:

Through this, we came up with the following HMW questions:

  1. HMW improve the app’s usability for new Chicago residents/users?

  2. HMW make it easier for users to plan routes and trips all within the same app?

  3. HMW reorganize features to be more easily accessible/more obvious to users?

  4. HMW make the navigation and payment process more cohesive/smooth for users?

Using these interviews, we also found some of the user experiences and journeys through navigation
